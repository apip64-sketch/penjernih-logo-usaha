# Penjernih Logo Usaha

Buatkan web app bahasa Indonesia bernama "Penjernih Logo" untuk penjual tas custom.

Fitur:

1. Upload gambar logo/desain (PNG/JPG, drag-and-drop + tombol pilih file, bisa dari HP)

2. Pilihan skala pembesaran: 2x dan 4x

3. Proses semuanya di browser (tanpa server, tanpa API key) pakai canvas upscaling + penajaman otomatis

4. Tampilan perbandingan sebelum/sesudah dengan slider geser

5. Tombol download hasil sebagai PNG

6. Desain bersih, mobile-friendly, warna netral cocok untuk usaha

Tambahkan teks bantuan singkat: "Cocok untuk logo sederhana. Untuk foto kompleks, hasil terbatas."
